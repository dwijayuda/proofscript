# v0.7.0 Lean 4.34 alignment

Semantic compatibility with Lean 4.34 is distinct from a runtime dependency on Lean. The reference Lean pipeline remains the oracle; a standalone TypeScript frontend plus pskernel may implement the same profile only with conformance evidence.

Lean 4.35.0-rc2 is watched for future rebase work and has no normative force in v0.7.0.
