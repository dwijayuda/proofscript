# Changelog — v0.6.1 Language Reference Draft

## Theme

**Integrated language reference from Lean reference study and ProofScript v0.5.2**

## Added

- Full `ProofScript_Language_Reference_v0.6.1_authoritative_draft.md`.
- Complete D/E/X feature registry appendix.
- Lean reference coverage map.
- Formal proof obligation appendix.
- TypeScript runtime profile appendix.

- Version manifest template.
- Example `.ps` files.
- Frontend proof roadmap and parser/lowering matrices.

## Preserved

- Lean 4.33.1 as semantic baseline.
- L/D/E/X surface model.
- `const` and `function` as contextual D-class declaration aliases.
- D-CALL as first proof target.
- E-class surface exceptions as S1-specified only.

## Not admitted

- Block-bodied `def/function` remains a candidate, not v0.6.1 normative syntax.
- TypeScript `<T>` generics are not admitted.
- Arrow lambdas are not admitted.
- JS statement block semantics are not admitted.
