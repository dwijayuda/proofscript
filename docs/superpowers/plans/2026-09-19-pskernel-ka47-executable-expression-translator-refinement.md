Goal: add a narrow source-bound preflight scaffold for the executable expression translator refinement bridge without changing trusted PSKernel semantics, kernel codec, Core format, or certificate format.

Boundary:
- no trusted semantic package edits;
- no Core format change;
- no new formal obligation unless strict Lean4Lean checking passes;
- no executable PSKernel refinement claim.

Implementation shape:
1. one Lean bridge scaffold under `assurance/ka47/`;
2. one gate tool under `tools/`;
3. one focused test under `tools/`;
4. JSON/MD reports generated by the gate;
5. anti-spaghetti guard against semantic package touches and oversized KA-47 files.
