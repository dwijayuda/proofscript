## Exact raw-kernel metadata differential

A new exact fixture, `RecursorMetadataNativeDifferential.lean`, submits seven
inductive declarations directly through:

```text
Lean.addDecl (.inductDecl ...)
```

This is important: the comparison does not depend on Lean surface-syntax
parameter inference. It observes the `RecursorVal` objects produced by the
pinned kernel for the same declared parameter/index split that ProofScript sees.

The seven shapes cover:

- nullary one-constructor type;
- one nonrecursive field;
- two-constructor list-like direct recursion;
- a uniform datatype parameter;
- an explicitly declared index with a constructor-local index field;
- Eq-like indexed singleton Prop with `k = true`;
- singleton Prop with a data field and `k = false`.

For every shape, the normalized ProofScript and exact-Lean lines are **identical**
for:

- `numParams`;
- `numIndices`;
- `numMotives`;
- `numMinors`;
- first-minor position;
- first-index position;
- major position;
- K classification;
- rule constructor names and field counts.

Result: **7/7 TypeScript + 7/7 exact Lean, zero mismatch**.
