# KERNEL-quotients0 profile

Semantic baseline: ProofScript Language Reference v0.1 / Lean 4.33.1 (`819816b2e0a3bf405af45ae5c7af2491d8f5bee6`).

This is a **kernel-only hardening profile**. It does not change the K3c source frontend producer and it adds no parser syntax.

## Core/artifact

- Core artifact format: v13 for kernel-only quotient fixtures.
- New trusted declaration marker: `{ kind: "quot", name: "Quot", levelParams: [] }`.
- v13 `KERNEL-quotients0` artifacts intentionally carry no frontend module metadata.
- Historical v1-v12 artifacts remain accepted through their original codecs/profiles.

## Admission

The marker is accepted only when the environment already contains the canonical Lean-compatible `Eq` inductive and `Eq.refl` constructor shape. Admission is atomic and refuses pre-existing `Quot`, `Quot.mk`, `Quot.lift`, or `Quot.ind` names.

On success the kernel installs exactly:

- `Quot`
- `Quot.mk`
- `Quot.lift`
- `Quot.ind`

with the Lean 4.33.1 universe parameters, types and BinderInfo.

`Quot.sound` is **not** generated by the marker. It is an explicit axiom/library declaration and therefore appears in assumption closure.

## Conversion

Trusted WHNF implements the Lean quotient computation rules:

- `Quot.lift f h (Quot.mk r a)` reduces to `f a`.
- `Quot.ind h (Quot.mk r a)` reduces to `h a`.

Only kernel-installed quotient primitive entries trigger these reductions; serialized artifacts cannot forge a `quotient` environment declaration kind.

## Security/replay

The v13 strict decoder rejects malformed markers, frontend module metadata, forged quotient primitive entries, and v12 attempts to smuggle the new marker. The standalone verifier replays v13 quotient fixtures without parser, elaborator, plugins, or Lean.

## Exact Lean evidence

`tools/kernel-quotient-tests.ts` authenticates exact Lean 4.33.1 when available and checks the primitive surface plus definitional computation. Missing Lean does not affect standalone checking and is reported as oracle-unavailable by the test workflow.

## Deferred

This profile does not claim full kernel completion. Canonical Eq bootstrap alignment, structure eta, complete inductive/recursor/Prop-elimination semantics, mutual/nested inductives, and final resource/adversarial hardening remain open.
